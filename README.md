# uchinokocheck

オリジナルキャラクター（うちの子）の設定を、1枚の設定シートにまとめるツール。

## 機能
- 基本設定の入力欄：名前 / ふりがな / 年齢 / 性別 / 一人称 / 身長 / 誕生日 / 血液型 / テーマカラー / 口癖 / 好きなもの / 苦手なもの / 設定メモ
- チェックリスト式のタグ：「外見の特徴」「性格」「雰囲気・属性」の3カテゴリ×12タグから、当てはまるものをいくつでも選べます
- 入力に合わせて設定シートがその場でプレビュー表示（名前の見出しはテーマカラーで彩色、タグはカテゴリ別のチップ表示）
- 「文章でコピー」ボタンで、シート全体をプレーンテキストとしてコピーできます
- 「全部消す」ボタンで、入力内容と保存データをまとめて消去できます

## データについて
- 入力内容はブラウザの localStorage（キー `uchinokocheck-v1`）に自動保存され、次回開いたときに復元されます。
- サーバーへ入力内容が送信されることはありません。

## 動かし方
```bash
pip install -r requirements.txt
python app.py
```

## テスト
```bash
pip install pytest
pytest tests/
```
